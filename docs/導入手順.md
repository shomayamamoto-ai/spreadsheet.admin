# 導入手順(ローカルAI版)

事務所のパソコン1台に入れて使うまでの手順です。
すべての処理はそのパソコンの中で行い、書類の中身を外部に送ることはありません。

---

## 0. 用意するもの

| もの | 内容 |
|---|---|
| パソコン | Windows または Mac。メモリ16GB以上が目安(**【推測】** 資料によって8〜16GB以上と幅があるため、余裕を見た目安) |
| Node.js | 無料。[公式サイト](https://nodejs.org/ja)から「LTS(推奨版)」を入れる |
| Ollama | 無料のローカルAIソフト。[公式サイト](https://ollama.com/)から入れる |
| このフォルダ一式 | 事務所のパソコンの、分かりやすい場所に置く |
| 顧問先の一覧 | 顧問先コード・正式名称・略称・決算月。会計ソフトから書き出したCSVがあると早い |

インターネットが必要なのは、上のソフトとAIのモデルを最初に入れるときだけです。

---

## 1. ローカルAIのモデルを入れる(初回のみ)

Ollama を起動したあと、次のコマンドを実行します。
モデル名は例です。試験運用で、実際の書類を使って2〜3種類を比べて選んでください。

文字を読むモデル:

```bash
ollama pull qwen3:8b
```

スキャンした紙の書類も読む場合は、画像を読むモデルも入れます:

```bash
ollama pull qwen2.5vl:7b
```

---

## 2. 起動する

- Windows:`local` フォルダの **`起動_Windows.bat`** をダブルクリック
- Mac:`local` フォルダの **`起動_Mac.command`** をダブルクリック

初回は準備に少し時間がかかります。そのあと、ブラウザで操作画面が開きます。
黒い画面(起動したウィンドウ)を閉じると終了します。

---

## 3. 事務所に合わせて設定する(画面の「設定」)

初回は「設定」が自動で開きます。

| 設定 | 内容 |
|---|---|
| 事務所名 | 画面の上に表示されます |
| 受付フォルダ | 職員がPDFを入れる場所。今の保存フォルダを指定してもかまいません |
| 保存先フォルダ | 仕分けたPDFと、一覧表(`書類一覧.csv`)を置く場所 |
| フォルダ名・ファイル名の付け方 | 事務所のいつもの付け方に合わせます。見本を見ながら決められます |
| 顧問先マスタ | 「CSVから読み込む」か、表に直接入力します。**略称(書類に出てくる呼び方)を別名に入れると、読み取りの精度が上がります** |
| 書類種別 | 使わないものはチェックを外します。事務所独自の帳票は「書類種別を追加」で足します |
| ローカルAI | 標準は「ルールで迷った書類だけに使う」 |
| スキャンした書類 | 紙をスキャンしたPDFも扱う場合はチェックを入れます |

最後に「設定を保存」を押します。

---

## 4. 精度を測る(本格導入の前に)

実際のPDFを50〜100件と、その正解表を用意して、どれくらい正しく仕分けられるかを測ります。
ファイルは動かしません。

```bash
npm run evaluate -- --config local/config.json --folder <PDFのフォルダ> --answers <正解表.csv>
```

正解表は、`local/正解表.template.csv`(見出しだけの空のひな形)に1件1行で書き足して作ります。
「**誤って自動仕分け:0件**」になるまで、表題の目印や顧問先の別名を足して調整します。

---

## 5. 毎日の使い方

1. 職員は、今まで通りPDFを受付フォルダに入れる
2. 担当者が画面で「試し実行」→「仕分けを実行」(または自動実行を設定)
3. 「要確認の書類」だけ、PDFを見ながら書類種別・顧問先・期間を選んで「確定」
   - 「次から自動で読めるように」にチェックを入れたまま確定すると、
     その帳票の表題や顧問先の呼び方を覚えます。使うほど、事務所の帳票に合っていきます
4. 一覧表(`書類一覧.csv`)は、Excel や Googleスプレッドシートで開けます

---

## 6. 困ったとき

| 状態 | 対処 |
|---|---|
| 画面に「ローカルAI:使えません」 | Ollama を起動する。モデル名が設定と同じか確かめる(ルールだけでも動き続けます) |
| 要確認が多い | 要確認の書類を確定するときに「覚える」を使う。顧問先マスタに略称(別名)を足す |
| スキャンした書類が読めない | 「設定」で文字起こしをオンにし、画像を読むモデルを入れる。JPEG以外の形式で保存するスキャナーには未対応(スキャナーの保存形式を「カラー/グレー(JPEG)」にする) |
| 画面が開かない | 黒い画面に表示されたアドレス(`http://127.0.0.1:8730`)をブラウザに入力する |
