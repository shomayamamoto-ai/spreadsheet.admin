# 料金プラン案(導入支援サービス)

> 対象:職員6〜30人の会計事務所・税理士事務所
> 表記:**【事実】** 出典のある情報/**【仮定】** 計算のための仮の数字/**【推測】** 提案者の見立て
> 金額はすべて税別。**最終的な金額は、提供者(しょーまさん)が決めてください。**

---

## 1. 結論(提案)

| 項目 | 職員6〜15人 | 職員16〜30人 | 内容 |
|---|---|---|---|
| 初期導入費 | **20万円** | **30万円** | 下の「3. 初期導入に含む作業」 |
| 月額保守 | **1.5万円** | **2.5万円** | 下の「4. 月額保守に含むもの」 |
| 最低契約期間 | 12か月 | 12か月 | 初期費用を回収するため |

**【推測】** この価格は、類似サービスの価格帯(2章)と、事務所が得られる効果(5章)の両方から見て、
「効果が出る事務所には十分に安く、効果が小さい事務所には売るべきではない」水準です。
**売る前に、事務所の月の書類件数を必ず確認してください**(5章)。

## 3. 初期導入に含む作業

| 作業 | 内容 |
|---|---|
| 事前のヒアリング | 書類の種類・月の件数・今のフォルダ構成・共有フォルダ(NAS)の確認 |
| 処理用パソコンの準備 | Node.js・ローカルAI(Ollama)・モデルの導入、導入チェック(`npm run doctor`)で点検 |
| 事務所に合わせた設定 | フォルダ名・ファイル名の付け方、顧問先マスタの取り込み、利用者(職員)の登録 |
| 帳票の調整 | よく使う帳票(標準10種類まで)の表題・項目の調整 |
| 精度の測定と報告 | 実際のPDF100件で測定し、精度レポートを提出(誤って自動仕分け0件を確認してから本番へ) |
| 職員向けの説明 | 1時間程度(要確認の書類の確定のしかた) |
| 引き渡し | 導入手順書・操作の案内・導入効果レポートの見方 |

**【仮定】** 作業時間の目安:ヒアリング2時間+現地1日+リモート調整1〜2日。

## 4. 月額保守に含むもの

- 帳票ルールの調整(月2件まで)
- 問い合わせ対応(メール・電話、平日日中)
- 月1回のリモート点検(導入チェック)と、導入効果レポートの送付
- プログラムの更新

**含まないもの(別料金)**:訪問対応、帳票の大幅な追加、パソコン・NASの故障対応、データの復旧

| 処理用パソコンの手配 | 実費+手数料 |

## 5. 事務所にとって元が取れるか(売る前の確認)

**【仮定】** 自動で仕分けできる割合8割、職員の人件費を時給2,500円として計算。

| 月の書類件数 | 1件1分の場合 | 1件2分の場合 |
|---|---|---|
| 300件 | 4.0時間=約1.0万円 | 8.0時間=約2.0万円 |
| 600件 | 8.0時間=約2.0万円 | 16.0時間=約4.0万円 |
| 1,000件 | 13.3時間=約3.3万円 | 26.7時間=約6.7万円 |
| 1,500件 | 20.0時間=約5.0万円 | 40.0時間=約10.0万円 |

**読み取り方**

- 月300件・1件1分の事務所では、削減額(約1万円)が月額保守(1.5万円)を下回ります。**この事務所には、時間の削減だけでは勧められません。**
- 月600件以上、または1件の仕分け(探す・名前を付ける・移す)に2分以上かかっている事務所なら、月額保守を上回る効果が見込めます。
- **【推測】** 時間以外の効果(書類を探す時間の短縮、保存漏れ・二重保存への気づき、担当者による保存ルールのばらつきの解消)も価値になりますが、金額にしにくいため、上の表には入れていません。

**営業の手順(提案)**

1. ヒアリングで、月の書類件数と、1件の仕分けにかかる時間を聞く(または1週間測ってもらう)
2. 上の表で、月額保守を上回る効果があるかを、事務所と一緒に確認する
3. 効果が見込める事務所にだけ、精度の測定(有償の試験導入でも可)を提案する

## 6. 補助金について

- **【事実】** 2026年度から「IT導入補助金」は「デジタル化・AI導入補助金」になり、導入コンサルティング・設定・研修・保守なども対象経費に含まれます。ただし、事務局に登録されたITツールと、登録された「IT導入支援事業者」を通した申請が条件です。
  (出典:[中小企業庁 概要資料](https://www.chusho.meti.go.jp/koukai/yosan/r8/digital_ai_summary.pdf)、[補助金ポータル](https://hojyokin-portal.jp/columns/ai-agent-hojyo)。補助率などは公募要領で要確認)
- **【推測】** 今のままでは対象になる可能性は低いです。対象にするには、支援事業者としての登録と、ツールの登録審査が必要で、個人での対応は負担が大きいと見込まれます。
  **当面は補助金を前提にしない価格**にし、件数が増えてから登録を検討するのが現実的です。

## 7. この料金案の弱点(反対意見)

| 弱点 | 対策 |
|---|---|
| 小さな事務所では元が取れない | 5章の確認をしてから売る。小さな事務所には「ルールだけで動くGoogle版」の簡易導入(初期のみ)を別に用意する案も |
| 精度の実績がまだない | 最初の2〜3事務所は、試験導入(精度の測定まで)を割安にして、実績(精度レポート)を作る |
| 1人で保守を続けられるか | 保守の範囲(4章)を契約で明確にし、件数の上限を決める。問い合わせは導入チェックの結果を添えてもらう |
| 価格が安すぎる可能性 | 職員16〜30人の事務所で件数が多い場合は、効果に合わせて見積もりを上げる余地がある |
