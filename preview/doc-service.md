# サービス内容と役割分担(導入支援サービス)

事務所に渡す説明資料のひな形です。〔 〕の部分を、提供者と事務所に合わせて書き換えてください。

---

## サービスの概要

事務所のパソコン1台に「書類PDFの自動仕分け」の仕組みを導入し、
職員の皆さまが事務所内のネットワークから使える状態にして、引き渡します。
**書類の中身は、事務所のパソコンの外(提供者を含む)に送られません。**

## 役割分担

| 項目 | 提供者〔 〕 | 事務所〔 〕 |
|---|---|---|
| 処理用パソコン | 推奨の性能をお伝えし、設定する | 用意する(メモリ16GB以上が目安) |
| 共有フォルダ(NAS・社内サーバー) | 接続を設定する | 用意し、アクセス権を付ける |
| 顧問先マスタ | 取り込みを手伝う | 顧問先の一覧(コード・名称・略称・決算月)を用意する |
| 帳票の調整 | 調整し、精度を測定する | 見本のPDFと、正しい仕分け先(正解表)を用意する |
| 利用者の登録 | 管理者アカウントを作る | 職員のアカウントを管理する(追加・無効化) |
| 毎日の運用 | ― | PDFを受付フォルダに保存し、要確認の書類を確定する |
| 仕分け結果の最終確認 | ― | **事務所が行う**(自動の仕分けにも誤りはあり得るため) |
| バックアップ | 方法をご案内する | 保存先フォルダのバックアップを行う |
| 保守 | 月1回のリモート点検、帳票ルールの調整(月2件まで)、問い合わせ対応 | 点検の時間を確保する |

## 個人情報の取扱い

- 書類の読み取り・AIでの判定・ファイルの移動は、すべて事務所のパソコンの中で行います。
- 提供者が保守で事務所のパソコンに接続するのは、**事務所の了承を得たときだけ**です。
  接続した日時と作業内容は、事務所に報告します。
- 提供者は、作業中に知った書類の内容を、事務所の許可なく外部に持ち出したり、他の目的に使ったりしません(秘密保持契約を結びます)。
- 精度の測定に使う見本のPDFは、事務所のパソコンの中で扱い、提供者のパソコンには持ち出しません。

## 導入までの流れと期間(目安)

| 段階 | 内容 | 期間 |
|---|---|---|
| 1. ヒアリング | 書類の種類・件数・フォルダ構成の確認、効果の試算 | 1〜2時間 |
| 2. 準備 | 処理用パソコン・共有フォルダの準備(事務所) | 1〜2週間 |
| 3. 導入 | 設定・帳票の調整・利用者の登録 | 現地1日+リモート1〜2日 |
| 4. 精度の測定 | 実際のPDF100件で測定し、精度レポートを提出 | 1週間 |
| 5. 本番開始 | 職員向けの説明(1時間)、運用開始 | ― |

## 動作の前提

- 処理用パソコン:Windows 10/11 または macOS。メモリ16GB以上が目安(ローカルAIを使う場合)
- 書類:会計ソフトなどから出力したPDF(文字情報を持つもの)。スキャンした書類はオプション
- ネットワーク:事務所内のLAN。インターネットへの接続は、導入時と更新時だけ必要
