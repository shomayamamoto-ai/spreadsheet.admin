# PDF仕分けアシスタント(税理士事務所向けデモ)

会計ソフトなどで作成し、PDFにして保存した書類を読み取り、
**書類種別・顧問先・対象期間・金額**をスプレッドシートに整理するデモです。
読み取った結果をもとに、ファイル名を付け直し、
「顧問先 / 年度 / 書類種別」のフォルダへ自動で仕分けます。

- 提案サイト(ブラウザで見る提案資料):`site/index.html`
- 提案資料:[docs/proposal.md](docs/proposal.md)
- 事務所への導入手順(そのまま渡せる手順書):[docs/導入手順.md](docs/導入手順.md)
- 販売資料(料金プラン案・サービス内容と役割分担・契約書の骨子):[docs/販売資料/](docs/販売資料/)
- 製品名・提供者・問い合わせ先の変更:`local/brand.js`(画面・ログイン・レポートの表示が変わります)

主なコマンド:

| コマンド | 内容 |
|---|---|
| `npm run local:app` | 操作画面を起動(Windows は `local/起動_Windows.bat`、Mac は `local/起動_Mac.command` をダブルクリック) |
| `npm run doctor -- --config local/config.json [--full]` | 導入チェック(必要なものがそろっているかを点検し、直し方を表示) |
| `npm run evaluate -- --config … --folder … --answers …` | 精度の測定(精度レポートのHTMLも作成) |
| `npm run report -- --config local/config.json` | 導入効果レポート(HTML)を作成 |
| `npm test` | 自動テスト |
- デモ用のサンプルPDF(すべて架空データ。本番では使いません):[demo/samples/](demo/samples/)

## フォルダ構成

| パス | 内容 |
|---|---|
| `src/extractor.js` | 読み取りルールの本体(書類種別・顧問先・期間・金額の判定) |
| `src/pdftext.js` | pdf.js で取り出した文字を「行」にまとめる処理 |
| `src/privacy.js` | 個人情報を伏せ字にする処理(相談用) |
| `demo/` | ブラウザで動くデモ画面(提案の場で見せる用) |
| `local/` | **ローカルAI版**(事務所のパソコンで動く。ルール+パソコン内のAI)。`server.js` と `ui.html` が操作画面、`sorter.js` が仕分けの本体、`settings.js` が事務所ごとの設定と学習、`ocr.js` がスキャンした書類の文字起こし、`evaluate.js` が精度の測定 |
| `gas/` | Google Apps Script 版(Googleドライブ+スプレッドシートで動く。ルールのみ) |
| `scripts/generate_samples.py` | サンプルPDFを作るスクリプト |
| `test/` | 自動テスト |
| `test/fixtures/` | 自動テスト専用の架空データ(顧問先マスタ・正解表・スキャン見本)。本番では使いません |

`demo/extractor.js`・`demo/pdftext.js`・`demo/privacy.js`・`gas/Extractor.js` は、`src/` からの自動コピーです。
ルールを直すときは `src/` を編集し、`npm run build` を実行してください。


## 2. ローカルAI版のセットアップ(おすすめ)

事務所への導入は [docs/導入手順.md](docs/導入手順.md) の順に進めてください。
以下は、その要点と技術的な補足です。

### 事務所ごとに合わせられること(プログラムの書き換えは不要)

| 項目 | 方法 |
|---|---|
| 事務所名・フォルダ | 画面の「設定」 |
| フォルダ名・ファイル名の付け方 | 画面の「設定」。`{顧問先}` `{顧問先コード}` `{顧問先名}` `{年度}` `{期間}` `{書類種別}` を組み合わせる(見本つき) |
| 顧問先マスタ | 画面の「設定」で入力、またはCSVを読み込む |
| 書類種別 | 画面の「設定」で、使わない種別を外す・独自の帳票を追加・表題の目印を足す |
| 帳票の表題・顧問先の呼び方を覚える | 要確認の書類を確定するとき、「次から自動で読めるように」にチェック |
| スキャンした紙の書類 | 画面の「設定」で文字起こしをオン(画像を読むモデルが必要) |

初回の起動では設定ファイル(`local/config.json`)が自動で作られ、画面の「設定」が開きます。

### スキャンした紙の書類(画像のPDF)

- PDFの中のページ画像(JPEG)を取り出し、このパソコン内の「画像を読めるAI」で文字起こしします。外部には送りません。
- 文字起こしは数字などを読み間違えることがあるため、**標準では自動で仕分けず「要確認」にします**(書類種別・顧問先・期間は入力済みの状態)。人が確認して確定してください。
- 対応しているのは、ページを JPEG 画像として保存するスキャナーのPDFです(多くの複合機の「カラー/グレー」保存)。白黒2値(JBIG2・CCITT)形式には、まだ対応していません。

書類の中身を事務所のパソコンから一切出さずに、ルール+ローカルAIで読み取ります。
AIは、ルールで迷った書類だけに使います。

### 準備するもの

- Node.js(18以上)
- [Ollama](https://ollama.com/)(パソコン内で動く無料のAIソフト)
- メモリ16GB以上のパソコン(目安。モデルの大きさで変わります)

### 手順

1. Ollama をインストールして起動し、日本語に対応したモデルを入れる(モデル名は例です)

```bash
ollama pull qwen3:8b
```

2. このフォルダで部品を入れる

```bash
npm install
```

3. 設定ファイルと顧問先マスタを用意する
   - `local/config.template.json` をコピーして `local/config.json` を作り、
     受付フォルダ(`inbox`)・保存先フォルダ(`archive`)・顧問先マスタ(`clients`)・モデル名を書く
   - 顧問先マスタは `local/顧問先マスタ.template.csv`(見出しだけの空のひな形)と同じ形のCSV
     (顧問先コード,顧問先名,別名(;区切り),決算月)
4. **操作画面を起動する(おすすめ)**
   - Windows:`local/起動_Windows.bat` をダブルクリック
   - Mac:`local/起動_Mac.command` をダブルクリック
   - ブラウザで操作画面(`http://127.0.0.1:8730`)が開きます。
     黒い画面(起動したウィンドウ)を閉じると終了します。

### 操作画面でできること

| 操作 | 内容 |
|---|---|
| 要確認 | PDF・入力欄・仕分け先の見本を1画面に表示。顧問先は入力して絞り込み、期間は書類種別に合わせた入れ方。確定すると次の書類へ(Ctrl+Enter でも確定)。重複や不要な書類は「除外」で削除候補フォルダへ(削除はしません) |
| 仕分け | 受付の件数・今月の自動仕分け率・ローカルAIの状態を表示。「試し実行」「仕分けを実行」、自動実行(15・30・60分ごと) |
| 記録 | 仕分け済みの書類を、顧問先・書類種別・月で探し、保存場所をコピー。導入効果レポートを開く |
| 設定 | 事務所名・フォルダ・名前の付け方・顧問先マスタ・書類種別・ローカルAI・利用者(管理者のみ) |

標準では、操作画面はこのパソコンからしか開けません。職員のパソコンから使う場合は、
設定ファイルに `"server": { "mode": "lan" }` を書き足し、職員ごとの ID とパスワードを登録します
(手順は [docs/導入手順.md](docs/導入手順.md) の「2-2」)。
画面は外部の部品を一切読み込まないため、インターネットにつながっていなくても動きます。

### コマンドで動かす場合

試し実行(ファイルは動かさず、仕分けの予定だけを表示):

```bash
npm run local -- --config local/config.json
```

本番(ファイルを移動し、保存先に `書類一覧.csv` を追記):

```bash
npm run local -- --config local/config.json --apply
```

画面を開かずに定期実行したい場合は、Windows の「タスク スケジューラ」や Mac の `launchd` などで、
本番のコマンドを15分ごとに実行してください。

### 設定(`ai`)

| 項目 | 内容 |
|---|---|
| `mode` | `fallback`:ルールで迷った書類だけAIを使う(おすすめ)/`always`:全書類でAIにも確認させる/`off`:AIを使わない |
| `url` | ローカルAIの住所。**`localhost` か `127.0.0.1` しか指定できません**(外部を指定するとエラー) |
| `model` | Ollama のモデル名。実際の書類で2〜3種類を比べて選んでください |
| `timeoutSec` | 1件あたりの待ち時間の上限(秒) |

### AIの答えの扱い

- 書類種別・顧問先は、候補(種別一覧・顧問先マスタ)の中からしか選ばせません。
- AIには「根拠にした文章」も答えさせ、その文章が本当にPDFにあるかを照合します。
  照合できない答えは使いません。
  一覧の「AIで補った項目」列には、照合に通って採用した項目だけを記録します。
- ルールとAIの判定が食い違ったときは、ルールの値を残して「要確認」にします。
- Ollama が起動していないときは、ルールだけで処理を続けます。

### Googleスプレッドシートで見る

保存先フォルダを「パソコン版 Google ドライブ」の同期フォルダにすると、
`書類一覧.csv` と仕分けたPDFがGoogleドライブにも反映されます。
CSVは、Googleスプレッドシートの「ファイル → インポート」で取り込めます。
(AIの処理はパソコン内で終わっており、Googleに渡るのは、これまで保存していたPDFと一覧の項目だけです)

## 3. Google Apps Script 版のセットアップ(AIを使わない版)

1. Googleドライブに、次の2つのフォルダを作る
   - **受付フォルダ**(PDFを放り込む場所)
   - **保存先フォルダ**(仕分け後のフォルダが作られる場所)
2. 新しいGoogleスプレッドシートを作り、
   「拡張機能」→「Apps Script」を開く
3. `gas/` の3ファイルを貼り付ける
   - `Code.js` → `コード.gs` に貼り付け
   - `Extractor.js` → ファイルを追加して貼り付け
   - `appsscript.json` → 「プロジェクトの設定」で
     「appsscript.json をエディタで表示する」をONにして貼り付け
     (**必ず貼り付けてください**。外部へ送信できないようにする権限の設定が入っています)
4. 左側の「サービス」から **Drive API** を追加する
   (`appsscript.json` を貼り付けた場合は追加済みになります)
5. スプレッドシートを再読み込みし、
   メニュー「PDF仕分け」→「① 初期設定」を実行(初回は権限の許可が必要)
6. 「設定」シートに、受付フォルダと保存先フォルダのIDを入力
   (フォルダURLの `folders/` の後ろの文字列)
7. 「顧問先マスタ」シートに、顧問先コード・正式名称・決算月を入力
8. 受付フォルダにPDFを入れ、「② 受付フォルダを今すぐ読み取る」を実行
9. 問題なければ「自動読み取りをON(15分ごと)」を実行

### 重複の疑いになった書類の扱い

顧問先・書類種別・対象期間が同じ書類がすでに仕分け済みの場合、
「重複の疑い」として `_要確認` フォルダへ移します。
不要ならステータスを「除外」にし、別の書類なら内容を直して確定してください。

### 保存状況シート

「保存状況」シートには、顧問先マスタの顧問先ごとに、
書類種別ごとの仕分け済み件数が数式で表示されます(0件は「未保存」)。
顧問先マスタを更新したら、メニューの「保存状況シートを作り直す」を実行してください。

### 要確認になった書類の扱い

自信がない書類は `_要確認` フォルダへ移り、
「書類一覧」シートにオレンジ色で記録されます。
書類種別・顧問先名・対象期間をシートで直してから、
その行を選んで「選択した行を確定して移動する」を実行してください。

## 4. 読み取りルールの調整

`src/extractor.js` の `DOC_TYPES` に、書類種別ごとの
「表題の言葉」「本文のキーワード」「一覧に載せる金額の項目名」をまとめています。

**サンプルは一般的な会計帳票をまねた架空のものです。**
実際に使っている帳票のPDFで試し、表題や項目名に合わせて調整してください。
調整したら、テストを実行して既存の判定が壊れていないか確認します。

```bash
npm test
```

対応している書類種別:月次試算表、決算書、法人税申告書、消費税申告書、源泉所得税納付書、
源泉徴収票・年末調整、法定調書合計表、給与支払報告書、償却資産申告書、届出書・申請書、議事録、
総勘定元帳、請求書。

対応している期間の書き方(例):
「自 令和6年4月1日 至 令和7年3月31日」「令和7年3月期」「令和7年3月分」「令和7年1月から6月分」
「令和6年分」「R7.3.31現在」。届出書・議事録は、提出日・開催日で整理します。

## 5. 精度を測る(試験運用のとき)

事務所の実際のPDFで、どれくらい正しく仕分けられるかを数字で確かめます。
ファイルは一切動かしません。外部への通信もしません。

1. 試したいPDFを1つのフォルダに集める(例:50〜100件)
2. 正解表(CSV)を作る。形は `local/正解表.template.csv`(見出しだけの空のひな形)と同じです
   (ファイル名,書類種別,顧問先コード,対象期間(終了))。空欄の項目は採点しません
3. 実行する

```bash
npm run evaluate -- --config local/config.json --folder <PDFのフォルダ> --answers <正解表.csv>
```

結果の見方:

| 数字 | 意味 |
|---|---|
| 自動で仕分け | 人の確認なしで仕分けた件数 |
| うち誤り | **いちばん大事な数字**。間違った場所に、気づかないまま保存される件数。0件を目指します |
| 要確認に回った | 人が確認する件数。多いと手間が残ります |
| 項目ごとの正解率 | 書類種別・顧問先・対象期間のどこで間違えやすいか |

ローカルAIが使える場合は「ルールのみ」と「ルール+ローカルAI」を並べて表示するので、
AIを使う効果をそのまま比べられます。明細は正解表と同じフォルダの `評価結果.csv` に保存されます。

## 個人情報の扱い(中身を外に出さない仕組み)

| 仕組み | 場所 |
|---|---|
| ルールで読み取り、迷った書類だけパソコン内のAIが補う | `src/extractor.js`、`local/ai.js` |
| ローカルAI版の通信先を「このパソコン自身」に限定(外部を指定するとエラー、プログラム全体の通信も見張る) | `local/guard.js` |
| 操作画面は 127.0.0.1 だけで待ち受け、localhost 以外のアドレス・合言葉の無い操作・要確認フォルダ外のファイル表示を拒否 | `local/server.js` |
| 起動時に開いたブラウザだけが使える(1回だけ有効なログイン用アドレス+ブラウザ内だけの通行証)。同じパソコンを使う別の人は、画面・PDF・設定を見られない | `local/server.js` |
| 通信の見張りは3重(fetch のリダイレクト禁止、http の宛先確認、いちばん下の TCP 接続の宛先確認) | `local/guard.js` |
| 一覧(CSV)に書く文字が、Excel で数式として動かないようにする | `local/sorter.js` |
| AIの答えを、根拠の文章・顧問先マスタ・候補一覧と照合し、確かめられないものは使わない | `local/ai.js` の `verifyAI` |
| Google版:フォルダやPDFが公開設定なら処理しない/個人のGmailアカウントなら警告 | `gas/Code.js` |
| Apps Script に外部通信の権限(`script.external_request`)を付けない | `gas/appsscript.json` の `oauthScopes` |
| 外部送信の命令・権限が入っていないかを自動テストで確認 | `test/privacy.test.js` |
| 相談用の伏せ字版を作る(氏名・住所・個人番号・生年月日・電話・メール・口座・会社名・事務所名・金額・よくある名字・登録した言葉) | `src/privacy.js`(デモ画面の「伏せ字版」) |
| 手元で開くデモは、ブラウザの機能で同じ場所以外への通信を禁止 | `demo/index.html` の Content-Security-Policy |

`appsscript.json` の `oauthScopes` に外部通信の権限を追加すると、
`npm test` が失敗するようにしてあります。権限を追加する場合は、
事務所の規程を確認してから、テストもあわせて見直してください。

伏せ字機能は、見出しの無い珍しい名字の人名などを見落とすことがあります。
伏せ字版も、渡す前に必ず目で確認してください。

## 注意事項

- 顧問先の情報を扱うため、Googleドライブの共有範囲は事務所内に限定してください。
- Google Apps Script は1回の実行が最大6分などの制限があります
  ([公式の割り当て一覧](https://developers.google.com/apps-script/guides/services/quotas))。
  本スクリプトは1回20件・5分で区切って処理します。
